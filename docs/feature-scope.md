# Open Canvas 功能范围与验收清单

状态：草案 0.1
更新日期：2026-08-21

> 当前开发优先级以 [`canvas-parity-scope.md`](canvas-parity-scope.md) 为准：先完成画布基础能力、节点能力和可观察的 UI/交互对齐。本文件保留完整产品闭环与后续阶段边界；本地版不要求实现账号、空间、分享、团队协作或在线资源市场。

## 一、产品定义

Open Canvas 是一个独立的 AI 视频创作工作台。用户可以在 Codex 中用自然语言创建、修改和生成视频；同一个项目可在 Skill、CLI 和可编辑无限画布之间流转。

画布交互参考只用于确认布局、操作层级和状态反馈。产品不使用外部产品的名称、图标、素材、文案、接口或运行时代码。

## 二、范围分层

| 阶段 | 定义 | 交付目标 |
| --- | --- | --- |
| MVP | 可完成一次从创作指令到可预览、可迭代视频资产的闭环 | Skill、CLI、独立画布三端共享同一项目文档 |
| V1.1 | 提升画布内创作效率与素材复用能力 | 项目内上下文/素材引用、更多节点参数和批量操作；不新增全局角色库、素材库或历史面板 |
| V2 剪辑 | 提供非线性编辑能力 | 时间线、多轨、裁剪、拼接、转场、音频与导出编排 |
| 不在当前范围 | 商业化和多人协作能力 | 计费、套餐、额度、组织权限、实时协同、云端托管 |

### 2.1 本地版资源边界（已确认）

本地版优先保证一个项目从创意到生成的闭环，而不是建设跨项目的资源管理产品。角色设定、场景/风格和素材仍然可复用，但它们以当前项目中的普通上下文节点和本地文件引用存在，并随项目 JSON 一起流转。

| 需求 | P0 做法 | P0 明确不做 |
| --- | --- | --- |
| 角色设定 | 使用可连接多个镜头的“角色设定”节点，保存外观、身份描述和本地参考素材 | 跨项目角色库、角色检索/分组、云端同步和权限管理 |
| 素材复用 | CLI 导入到项目内内容寻址存储；画布既可用“本地素材引用”节点连接到镜头，也可在图像/视频镜头内直接关联项目内参考素材 | 全局素材库侧栏、素材市场、跨项目上传/下载管理和在线收藏 |
| 场景与风格 | 使用“场景/风格”上下文节点并连接到需要它的镜头 | 全局风格库、模板市场和历史资产中心 |
| 历史结果 | 在生成节点内查看被新版本替代的本地输出，并将其安全复用为当前镜头的参考素材 | 独立的全局生成历史面板 |

因此，画布的完整节点调色板仍包含角色、场景/风格和本地素材引用；它们不是被删掉，而是有意不升级为产品级“库”。

## 三、核心用户闭环

1. 用户在 Codex 输入创作目标，例如“制作三镜头科幻短片”。
2. 创作 Skill 创建脚本节点，并通过共享的脚本展开操作生成镜头计划和初始节点图。
3. CLI 在本地项目中创建或更新草稿，执行同一脚本展开操作，并在用户明确发起时调用用户配置的图像、视频生成服务。
4. 画布展示节点关系、参数、任务状态和生成素材。
5. 用户在 Codex 或画布中提出修改，例如“把镜头 2 改成夜景”。
6. 系统复制当前草稿为变体，只使受影响节点和下游节点失效并重新生成。
7. 用户选择一个草稿导出项目数据和最终媒体资产。

## 四、MVP 功能点

### 4.1 项目、草稿与文档

| 功能点 | 验收要求 |
| --- | --- |
| 本地项目 | 一个项目包含项目元数据、多个草稿、任务记录和共享素材索引。 |
| 草稿画布 | 每个草稿拥有独立节点图、连线、布局和版本号。 |
| 草稿变体 | 支持复制当前草稿并记录来源草稿；修改变体不得影响原草稿。 |
| 单一事实源 | Skill、CLI 和 Studio 对同一项目文档执行读写，不维护三份独立状态；CLI 打开 Studio 时通过本地回环桥接读取和显式保存该项目。 |
| 本地持久化 | 文档保存、导入和导出均经过结构校验；素材以项目内相对路径管理。 |
| 历史与撤销 | 支持撤销、重做和草稿级历史查看；历史记录可恢复到明确版本。 |

### 4.2 无限画布与基础交互

| 功能点 | 验收要求 |
| --- | --- |
| 无限坐标系 | 节点、参数区和连线随同一视口平移、缩放；应用级控制层固定。 |
| 画布导航 | 空白区域拖拽、空格拖拽、触控板双指滑动、抓手工具、缩放控制和适配视图均可导航。 |
| 节点选择 | 初始无预选节点；点击节点进入选中态并展示对应参数区，不应无意移动视口。 |
| 节点移动 | 选中工具下可直接拖动节点；拖动结束后位置写回项目文档。 |
| 多选与批量移动 | 按住 `Shift` 在空白处框选，或用 `⌘/Ctrl` 点击追加/取消节点选择；只有主选节点展开参数区，拖动任一选中节点会将整个选区的位置写回项目文档。 |
| 项目内分组 | 选择至少两个未分组节点后，通过工具栏或 `⌘/Ctrl+G` 创建持久化分组帧。分组只保存当前草稿的成员 ID，不复制节点、边、任务或素材；点击帧选中成员且不打开参数区，拖动帧以一次布局写入移动全部成员。 |
| 节点连接 | 从右侧输出端口连接到左侧输入端口；连线表达方向、类型和任务依赖。 |
| 节点删除 | 选中节点后按 `Delete` 或 `Backspace` 删除；多选时作为一组删除，同时清理相关连线和任务、让受影响下游重新待生成，并支持撤销。 |
| 节点复制 | 聚焦节点后按 `⌘/Ctrl+D` 创建一个带独立位置与待生成状态的项目内副本；不复制任务结果或跨项目资源。 |
| 节点组复制/粘贴 | 选中一个或多个节点后按 `⌘/Ctrl+C` 复制可编辑节点结构和仅位于选区内部的连线，按 `⌘/Ctrl+V` 在同一草稿粘贴为待生成节点组；保留当前项目的素材 ID 引用和相对布局，不复制任务、生成结果、素材字节或凭证。 |
| 布局与辅助 | 自动整理、项目内分组、网格吸附、连线显隐、小地图和缩放读数可独立操作。 |
| 快捷键 | 覆盖选择/抓手、缩放、适配、撤销/重做、添加节点、复制节点和整理画布等高频操作；当前画布使用 `N` 打开节点菜单、`Shift` 框选、`⌘/Ctrl` 追加选择、`⌘/Ctrl+C`/`⌘/Ctrl+V` 复制粘贴选中节点组、`⌘/Ctrl+G` 创建项目内分组、`Alt+Shift+F` 打开整理预览、`⌘/Ctrl+D` 复制聚焦节点。 |
| 响应式 | 窄视口保持同一画布坐标系；工具栏固定，用户通过平移与缩放查看节点。 |

### 4.3 节点调色板与节点通用能力

所有节点均应具备：标题、类型、位置、输入/输出端口、状态、参数、Prompt、上游依赖、结果资产和错误信息。

| 节点类型 | 数据角色 | MVP 能力 |
| --- | --- | --- |
| 文本 | 创意说明、旁白、标题、局部 Prompt | 编辑文本，作为下游生成上下文。 |
| 脚本 | 故事、分场、镜头计划 | 由 Skill 创建并可人工修改；可关联当前项目素材；共享 Core 操作按脚本的分行或句子创建项目内视频镜头，同时建立脚本依赖与相邻镜头顺序；Studio 与 CLI 均调用该操作。 |
| 图像镜头 | 静帧、关键帧、视觉设定 | 文生图、图生图、参考素材输入、尺寸与比例参数。 |
| 视频镜头 | 视频片段 | 文生视频、图生视频、本地参考素材输入、时长/比例/音频等约束。 |
| 编辑 | 对已有素材施加修改意图 | 在节点内关联当前项目的本地图片或视频，并通过 Prompt 描述裁剪、重绘、延展、替换或风格调整。 |
| 合成/输出 | 草稿级成片或输出选择 | 接收多个镜头，依照显式 sequence 边展示项目内顺序，并定义后续导出目标；本地多轨渲染仍是后续能力。 |
| 音频 | 配乐、音效、旁白 | 保存音频需求和当前项目内的素材引用；生成适配器可后续接入。 |
| 素材引用 | 复用当前项目已有图像或视频 | 通过普通“本地素材引用”节点或镜头输入引用，不复制源文件。 |
| 本地素材导入 | CLI 导入本地图片或视频 | 校验格式和大小，写入项目内内容寻址素材存储；不创建全局素材库 UI。 |
| 分析 | 从素材提取描述、镜头或标签 | 在节点内关联当前项目素材，产出可被脚本、图像和视频节点使用的结构化上下文。 |
| 角色/一致性 | 角色、场景、风格等可复用设定 | 作为普通上下文节点保存身份、外观和参考素材，供当前项目多个镜头连接。 |
| 布局分组 | 当前草稿的节点组织 | 保存至少两个成员节点 ID，派生帧边界并支持整组移动；没有输入/输出端口、生成任务或跨项目复用语义。 |
| 生成历史 | 查看单节点历史结果与执行版本 | 可将历史结果作为当前镜头输入安全复用，触发正常失效传播；不提供全局历史面板，也不把旧结果伪装为当前参数的输出。 |

### 4.4 创作、生成与 BYOK

| 功能点 | 验收要求 |
| --- | --- |
| 自然语言规划 | Skill 能把创作请求转换为脚本、镜头和依赖图，并说明将执行的修改。 |
| AI 默认路由 | Planner 可推荐提供方和模型；路由层验证能力后选择可用配置。 |
| Prompt 策略覆盖 | 用户可在 Prompt 中指定提供方、模型、比例、时长、音频或其他明确约束；不满足时返回可理解错误。 |
| 用户自带密钥 | 密钥只由本地 CLI 从环境变量读取；不进入画布、项目文件、日志、截图或前端。 |
| 图像生成 | 至少支持一个真实文生图适配器，以及确定性本地 Mock 用于演示和测试；图像节点可请求 1、2 或 4 个候选，支持的提供方会将每个候选保存为同一节点的项目内输出。 |
| 视频生成 | 至少支持一个真实文生视频或图生视频适配器，以及确定性本地 Mock。 |
| 任务生命周期 | 节点和任务记录显示 `queued`、`running`、`succeeded`、`failed`；进度只允许递增。 |
| 素材落库 | 成功结果下载为项目内持久素材，记录校验和和元数据，不持久化提供方 URL。 |
| 失效传播 | Prompt、参数或上游输入变化后，仅当前节点与依赖它的节点进入待更新状态。 |
| 局部重新生成 | 用户可只重跑指定节点或受影响子图，未受影响的成功节点保持不变。 |

### 4.5 Studio 工作台

| 区域 | 功能点 |
| --- | --- |
| 顶部控制层 | 项目名称、草稿切换、本地 JSON 导入/导出、保存状态，以及由 CLI 打开项目时的显式本地保存。 |
| 底部主工具栏 | 添加节点、选择/抓手、项目内分组、撤销/重做和快捷键。 |
| 左下控制组 | 自动整理、小地图、边显示、网格吸附和缩放。 |
| 节点选中态 | 外框、端口、快捷参数和随节点移动的内联参数编辑器。 |
| 图像/视频参数 | Prompt、参考素材、比例、尺寸、数量、时长、音频、高级设置和提交入口；当前数量仅适用于图像，且由提供方能力路由验证。 |
| 本地素材入口 | 由 CLI 导入；可在画布创建本地素材引用，或在选中图像/视频镜头内直接关联项目内参考素材；不展示项目级素材侧栏。 |
| 节点内历史 | 在生成节点内查看被替代的成功输出，并将其作为当前镜头参考素材安全复用；不展示全局历史面板。 |
| 失败详情 | 失败镜头在选中后可按需查看安全错误摘要、错误类型和下一步建议；重试仍通过 Codex 或 CLI 执行。 |
| 结果预览 | 节点内预览、元数据、全屏预览和下游输入已更新反馈；同次图像生成的多个候选可在节点内逐个查看；真实项目视频使用本地 `<video>` 播放器，演示封面仍作为静态图显示。 |

### 4.6 Codex Skill 与 CLI

| 表面 | MVP 功能 |
| --- | --- |
| Codex 创作 Skill | 依据对话组合项目初始化、节点与边的原子编辑、项目内分组、查看状态和导出；脚本展开、变体和生成仅在用户明确请求时执行。 |
| 第一方 CLI | 初始化项目、校验文档、读取/写入草稿、新增/修改/删除节点、使用 `group create` 创建项目内分组、管理边、通过 `script expand` 展开脚本、导入素材、提交/轮询任务、导出。 |
| 共享命令核心 | Studio 和 CLI 使用同一命令定义处理新增、删除、移动、整组移动、连线、参数修改、脚本展开、撤销和失效传播。 |
| 未来插件 | Codex Plugin 仅负责把 Skill 与 CLI 包装成分发入口，不产生新的业务数据模型。 |

### 4.7 导入、预览与导出

| 功能点 | 验收要求 |
| --- | --- |
| JSON 导入/导出 | 可导入完整项目快照；无效结构、远程 URL、绝对路径和敏感字段必须拒绝。 |
| 素材导入 | P0 支持图片、视频进入项目内内容寻址素材存储，可被镜头或素材引用节点使用；音频导入随音频资产类型扩展。 |
| 草稿预览 | 预览选中节点和合成输出；预览不暴露密钥或提供方内部地址。 |
| 成片导出 | 导出指定草稿的项目快照与已选主媒体资产；最终容器、编码与合成策略单独确认。 |

## 五、V1.1 功能点

1. 对齐等更完整的批量编辑操作，以及分组的重命名、嵌套和批量解除分组。
2. 当前项目内角色、场景、风格和素材引用节点的跨镜头复用。
3. 更完整的模型能力表和参数表单，按提供方能力动态约束。
4. 任务队列、可恢复轮询、重试策略和失败诊断。
5. 草稿对比、差异查看和变体管理。
6. 资产标签、搜索、筛选和引用链路追踪。
7. 画布快照、布局模板和故事板视图。
8. 更完整的桌面与移动端视觉状态覆盖。

## 六、V2 剪辑能力

V2 将“编辑节点的意图描述”升级为真正的非线性编辑工作区。该阶段不改变项目、草稿、素材和节点图的基础结构。

| 能力 | 验收要求 |
| --- | --- |
| 时间线 | 多轨视频、音频、字幕和效果轨道；时间码与帧率可见。 |
| 片段编辑 | 裁剪、分割、移动、复制、速度、冻结帧和替换片段。 |
| 合成关系 | 画布中的合成节点可打开对应时间线；时间线变化同步回项目文档。 |
| 视听处理 | 转场、滤镜、音量、淡入淡出、配乐、旁白和字幕。 |
| 播放预览 | 可播放当前时间线、查看波形和定位播放头。 |
| 渲染导出 | 按目标分辨率、帧率、码率和容器渲染最终成片。 |

## 七、当前明确排除项

1. 计费、套餐、积分、额度和成本优化。
2. 多人实时协同、组织成员、角色权限和云端共享空间。
3. 将 API Key 发送给浏览器、写入项目文档或保存到仓库。
4. 复制任何外部产品的品牌、素材、模型文案、私有接口或源代码。
5. 在 MVP 中实现完整的专业多轨剪辑器。

## 八、MVP 验收场景

给定指令“创建三镜头科幻短片”，系统创建主草稿、脚本节点、三个镜头节点和合成节点；用户配置本地密钥后，CLI 通过适配器生成图像或视频，画布展示进度和结果。

给定后续指令“将镜头 2 改成夜景”，系统复制主草稿生成夜景变体，只更新镜头 2 和其下游合成节点；镜头 1、镜头 3 和主草稿保持不变。

用户可在 Studio 中选择节点、拖动空白画布、移动节点、编辑 Prompt、调整参数、连接节点、查看生成结果，并导出指定草稿。通过 CLI 打开项目时，点击保存会在版本校验后写回同一份本地 `project.json`。

## 九、待确认决策

| 决策项 | 当前建议 | 需要确认的原因 |
| --- | --- | --- |
| MVP 成片输出 | 先导出项目 JSON 与主媒体资产，随后加入合成渲染 | 容器、编码和镜头拼接规则尚未定义。 |
| 实时视频提供方 | 先接入一个文生图和一个文生/图生视频提供方 | 适配器能力和密钥接入方式需要按实际 API 确认。 |
| 剪辑优先级 | 保持在 V2；MVP 只提供编辑意图节点 | 避免将完整 NLE 工作区阻塞创作闭环。 |
| 角色一致性 | V1.1 扩展当前项目内可复用的角色/场景上下文节点 | 需要先确定各模型的参考输入能力。 |
