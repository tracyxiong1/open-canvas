# 参考画布：本轮交互与样式复核

## 已实际观察到

1. 媒体节点是横向 16:9 预览卡；文本节点是紧凑的近方形卡，而不是统一的正方形节点。
2. 连接由源节点右侧的细小圆端口进入目标节点左侧的细小圆端口。静态边以细灰线为主，并在源端附近显示短蓝色状态段。
3. 选中媒体节点会同时显示：上方横向参数轨道、下方宽提示词/参数面板；选中文本节点会显示下方编辑面板。
4. 顶栏采用低密度的工作区/画布选择器和紧凑动作按钮；当前可见样本没有完整暴露底部新增菜单，不以猜测重做。

## 本地对齐决策

- 画布文档和四种内部连接语义保持不变，只调整 React Flow 投影和渲染层。
- 图片/视频使用 312 × 176 的横向画面，文本使用 176 × 176 的紧凑画面。
- 端口改为边缘圆点，边改为直线自定义边；仍由原有 handle id 校验 sequence / dependency。
- 节点点击只进入选中和参数态，不强制把相机重置到节点中心。
- 参数面板通过溢出渲染，不扩大 React Flow 节点 hitbox；否则会覆盖相邻节点并使其无法点击、拖动或连线。

## 本地实际验证

- 点击相邻节点：选中态和对应参数面板正常切换。
- 拖动节点：位置从 `(540, 125)` 变为 `(565, 139)`，位置写回成功。
- 从视频节点右端口拖到文本节点左端口：边数量从 `5` 变为 `6`，依赖关系创建成功。

## 未在本轮样本中可靠确认

- 参考画布在拖拽过程中的临时连线动画。
- 参考底部工具栏及新增节点菜单的完整状态。

这些部分保留现有可用交互，等待取得更完整的参考状态后再做细节对齐。
