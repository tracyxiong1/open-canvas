# Context Pack: 参考无限画布对齐

## 任务摘要

- 原始诉求：先实际运行参考画布的交互与样式，形成总结后再对齐本地无限画布，重点是连接点和细节交互。
- 当前理解：在不复用参考品牌、账号或素材的前提下，对齐已观察到的节点几何、端口、连线、选中态和顶栏信息密度；保留现有可编辑文档与生成语义。
- 非目标：本轮不改画布数据协议、模型调用、商业化、参考站账号数据或未观察到的完整底部工具栏行为。
