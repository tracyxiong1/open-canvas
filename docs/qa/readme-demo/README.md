## 复现

1. 按根 README 启动 Studio，直接打开本地地址，显示空画布。
2. 点击“添加节点”→“图像镜头”，输入“雨夜的城市街道，路面倒映灯光，低机位，电影感。”，点击“应用提示词”。
3. 将提示词改为“清晨的城市街道，柔和阳光，低机位，电影感。”，再次应用。
4. 点击顶部“打开”，选择本目录的 `demo-project.json`，再点击“整理画布”并保留布局。
5. 选中“旁白 · 开场”，打开输出设置，将语速改为 `1.15`。

原始录屏和截图只包含浏览器内容区域，没有地址栏、本地桥接令牌或提供方凭证。README 使用相对路径引用仓库内素材，不依赖第三方图片或视频托管服务。
