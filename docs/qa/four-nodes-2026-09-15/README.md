## 结论与范围

四节点首版已实现并通过本地回归：创建入口收敛为文本、图片、视频、音频，旧项目中的其他节点仍可读取与编辑。音频范围为 TTS、导入、播放和下载；生成由 Codex/CLI 显式执行。此记录不代表真实提供方或生成质量验收通过。

## 浏览器证据

使用第一方 CLI 创建独立临时项目，通过本地预览桥接加载，并使用 ego-browser 实际操作。生成显式指定 mock；PNG、MP4、WAV 均是确定性测试素材，WAV 为一秒静音。

- 新项目初始为空，添加菜单仅有四类节点；见 [桌面菜单](desktop-palette.png)。
- 音频弹窗使用原生播放器，读到 `duration=1`、`readyState=4`、`error=null`，播放后 `paused=false` 且进度增加；见 [音频播放](audio-playback.png)。
- 浏览器下载 WAV 与项目内容寻址资产的 SHA-256 一致：`56d4af65701c26df20bd4021eda95b6e830348ce3a746086079fe89285548dc9`。
- 在 390×844 视口实际打开音频输出设置并修改语速；见 [窄屏设置](compact-audio-settings.png)。点击保存后，从项目文件读回 `voice=alloy`、`speed=1.25`、`revision=18`，任务数仍为 3，没有自行发起生成。
- 修改要求后音频节点为待生成，旧任务保留。桌面设置见 [桌面音频设置](desktop-audio-settings.png)。
- 实际打开节点历史并选择第 1 次输出，保存后读回 `revision=19`、选中资产 ID 与原 WAV 一致；节点仍为待生成，音色和语速不变，任务数仍为 3。见 [历史结果选择](history-selected.png)。

验收发现行内编辑器随节点移出视口后，输出设置按钮无法触达。现将编辑器限制在视口水平边界，工具栏支持横向滚动；不修改节点坐标或自动平移画布。这一调整以可操作性为优先，替代历史视觉记录中允许参数卡片被屏幕边缘裁切的规则。

## 尚未验证

- 没有调用真实付费 TTS、生图或生视频 API，账户权限、音质、画质、时延及真实长任务仍需 BYOK 验收。
- Speech 是同步接口，中断后不能从官方服务续查；本地只保证不自动重发，不能保证未计费。
- 未提供音乐生成、声音克隆、波形剪辑或完整时间线编辑。文本节点是正文与提示词上下文，不是新增的独立 LLM 聊天服务。
- 导入音频的可播放性受浏览器编解码支持限制；TTS 输出限制为 WAV/MP3。
