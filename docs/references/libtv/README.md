# 无限画布交互参考

本文记录 2026-08-12 在已授权、已登录的 Devbox Chromium 会话中观察到的无限画布交互。参考材料只用于 Creator Canvas MVP 的交互设计，不构成运行时依赖，也不提供源站接口、账号或存储信息。

## 一、证据边界

- 视口：桌面端 `1440 × 900`，移动端 `390 × 844`。
- 画布：本次采集新建的未命名空白画布。
- 测试节点：一个文本节点和一个图片节点，内容均为本次输入的中性测试文案。
- 测试素材：通过图片节点生成的抽象蓝色圆形，不包含人物、账号或用户上传内容。
- 脱敏：所有保留截图均遮挡左上角品牌徽标和右上角账号头像区域；账号菜单始终关闭。
- 排除内容：生成完成时出现的促销弹窗包含二维码和人物头像，已关闭且未纳入证据。
- 禁止内容：采集过程中未读取或保存 Cookie、LocalStorage、手机号、验证码、网络请求或其他账号信息。

## 二、桌面端结构

桌面端采用固定控制层与可变换画布层：

1. 顶部控制层包含画布切换、工作流、故事板、分享和 Agent 入口。
2. 底部中央工具栏包含添加节点、选择/移动、工具箱、素材、角色、历史、快捷键和教程。
3. 左下角提供资产、自动整理、小地图、连线显隐、网格吸附和缩放入口。
4. 画布使用点阵背景，节点和连线随平移、缩放共同变换，顶部与底部控制层保持固定。
5. 空画布中央提供常用能力快捷入口；添加节点后，该空态入口消失。

## 三、节点、参数与连线

### 3.1 节点创建与选择

“添加节点”以浮层菜单展示文本、图片、视频、智能剪辑、导演台、逐帧分析、音频、脚本、素材库、上传和生成历史等入口。创建节点后，节点默认获得选中态。

选中态包含以下反馈：

- 节点外框高亮。
- 节点左右侧显示圆形连接端口。
- 节点下方展开参数区。
- 参数区随节点位于画布坐标系内，会随平移和缩放移动。

证据：

- [`desktop-1440x900-node-selected.png`](desktop-1440x900-node-selected.png)：文本节点创建后的选中态。
- [`desktop-1440x900-parameters.png`](desktop-1440x900-parameters.png)：图片节点参数区，包含参考、标记、风格、提示词、模型、比例、画质、分辨率、数量和提交入口。

### 3.2 连线

节点通过左右端口拖拽建立有向连接。已建立的连线显示为细线，并以蓝色动态标记表达方向。连接图片节点与文本节点后，上游生成完成会使下游节点出现“输入已更新”状态。

证据：

- [`desktop-1440x900-connection.png`](desktop-1440x900-connection.png)：两个节点之间的端口和有向连线。

## 四、画布导航

移动工具将拖拽解释为画布平移。平移只改变画布内容的位置，固定控制层不移动。

缩放菜单包含以下能力：

- 数值输入。
- 放大与缩小。
- 适合屏幕。
- 50%、100% 和 800% 快捷值。

50% 状态下节点、端口和连线等比缩小，底部工具栏和左下角缩放读数保持固定尺寸。自动整理会重新排列节点，并根据内容范围调整视口缩放。

## 五、生成状态与素材预览

图片节点的生成流程包含可观察的运行态和完成态：

1. 提交后，节点画面区域显示“生成中”和百分比进度。
2. 参数区的提交按钮切换为旋转状态，节点提供取消入口。
3. 生成完成后，节点直接显示结果和 `2048 × 1152` 尺寸。
4. 下游节点显示输入更新提示。
5. 结果保持画布内预览；本次单击结果未进入独立全屏预览。

## 六、移动端响应式行为

移动端保留同一画布坐标系，没有将节点重排为纵向页面流：

1. 顶部控制层压缩为画布切换等少量入口。
2. 底部主工具栏保持固定，并占用接近全部可用宽度。
3. “添加节点”菜单变为左侧覆盖式面板，宽度约为视口的一半。
4. 节点仍使用接近桌面端的固定宽度，可能横向超出视口。
5. 选中节点的参数区继续位于节点下方，也可能横向溢出。
6. 用户通过平移和缩放查看完整节点及连线；自动适配后的采集状态显示 56% 缩放。

## 七、MVP 实现约束

本次参考对 Creator Canvas MVP 形成以下交互约束：

- 画布变换与应用级控制层分离。
- 节点、参数区、端口和连线共享画布坐标系。
- 节点选中态需要同时提供外框、端口和参数反馈。
- 运行状态需要在节点内显示进度，并提供明确的取消入口。
- 完成结果需要直接在节点中预览，状态变化需要传播到下游节点。
- 移动端优先保留画布语义，通过固定工具栏、覆盖菜单、平移和缩放完成导航。
- 产品实现不得复用本参考中的品牌、文案、模型名称、图标或视觉资产。
