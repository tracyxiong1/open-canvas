## 一、证据边界

- 视口：桌面端 `1440 × 900`，移动端 `390 × 844`。

- 测试节点：文本、图片和视频节点，内容均为本次输入的中性测试文案。
- 测试素材：抽象蓝色圆形，不包含人物、账号或用户上传内容。
- 字体校正：页面中文原文正常，但默认字体栈未命中 Devbox 的中文字库。截图前仅在当前页面注入 `Noto Sans CJK SC` 字体回退；未修改或复制源站代码。
- 脱敏：所有保留截图均遮挡左上角品牌区域和右上角账号区域；账号菜单始终关闭。图中的黑色圆角块是有意保留的遮挡层。
- 排除内容：余额不足时出现的会员/充值页面未纳入证据，也未被误记为生成失败状态。
- 禁止内容：采集过程中未读取或保存 Cookie、LocalStorage、手机号、验证码、网络请求或其他账号信息。

## 三、桌面端结构

桌面端采用固定控制层与可变换画布层：

1. 顶部控制层包含画布切换、工作流、故事板、分享和 Agent 入口。
2. 底部中央工具栏包含添加节点、选择/移动、工具箱、素材、角色、历史、快捷键和教程。
3. 左下角提供资产、自动整理、小地图、连线显隐、网格吸附和缩放入口。
4. 画布使用点阵背景，节点和连线随平移、缩放共同变换，顶部与底部控制层保持固定。
5. 空画布中央提供常用能力快捷入口；添加节点后，该空态入口消失。

## 四、节点、参数与连线

### 4.1 节点创建与选择

“添加节点”以浮层菜单展示文本、图片、视频及多个业务入口。Open Canvas 只取其画布交互证据；当前产品范围提供自己的完整、通用创作节点调色板（编辑、分镜、镜头分析、音频、脚本和素材上下文等），它们使用独立的文案、图标、数据角色和生成语义，不是一对一映射或复用任何参考产品组件。

创建节点后，节点默认获得选中态：

- 节点外框高亮。
- 节点左右侧显示圆形连接端口。
- 节点下方展开参数区。
- 参数区随节点位于画布坐标系内，会随平移和缩放移动。

### 4.2 图片与视频参数

图片参数区可观察到参考素材、标记、风格、提示词、模型、比例、画质、分辨率、数量和提交入口。视频参数区可观察到参考素材、标记、特效、角色、运镜、提示词、模式、比例、分辨率、时长、数量、音频及高级设置。

这些字段只用于确定信息分组、密度、展开方式和移动端溢出行为；产品实现不得复用源站模型名、价格、积分或业务文案。

### 4.3 连线

节点通过左右端口建立有向连接。已建立的连线显示为细线，并以动态标记表达方向。上游图片生成完成后，下游文本节点出现“输入已更新”反馈。

源站连线只提供视觉证据。Open Canvas 的 `sequence` 与 `dependency` 语义以 `docs/architecture.md` 为准，不能从源站外观推断。

## 五、画布导航

- 中键拖拽可平移画布，节点与连线共同移动，固定控制层不移动。
- 缩放菜单包含数值输入、放大、缩小、适合屏幕，以及 50%、100% 和 800% 快捷值。
- 50% 状态下节点、端口和连线等比缩小，底部工具栏和左下角缩放读数保持固定尺寸。
- 自动整理会重新排列节点并适配视口；整理结果需由用户选择保留或还原。

- 不凭空补画 `queued`、`running`、`failed` 或视频预览。

## 七、移动端响应式行为

移动端保留同一画布坐标系，没有将节点重排为纵向页面流：

1. 顶部控制层压缩为画布切换等少量入口。
2. 底部主工具栏保持固定，并占用接近全部可用宽度。
3. “添加节点”菜单变为左侧覆盖式面板，宽度约为视口的一半。
4. 图片和视频节点仍使用接近桌面端的固定宽度，可能横向超出视口。
5. 选中节点的参数区继续位于节点下方，也可能横向溢出。
6. 用户通过平移和缩放查看完整节点及连线；固定工具栏不随画布变换。

## 九、MVP 实现约束

- 画布变换与应用级控制层分离。
- 节点、参数区、端口和连线共享画布坐标系。
- 节点选中态需要同时提供外框、端口和参数反馈。
- 运行状态需要在节点内显示进度；具体状态语义以本项目状态机为准。
- 完成结果需要直接在节点中预览，状态变化需要传播到下游依赖节点。
- 移动端优先保留画布语义，通过固定工具栏、覆盖菜单、平移和缩放完成导航。
- 产品实现不得复用本参考中的品牌、文案、模型名称、图标或视觉资产。
