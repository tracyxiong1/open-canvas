# Open Canvas 画布能力与交互对齐矩阵

状态：当前开发基准
更新日期：2026-08-21

## 一、当前目标

当前阶段只以可编辑创作画布为中心。验收对象包括画布导航、节点类型、节点状态和功能、连线、工具层、面板和桌面/窄视口交互。

生成服务、Skill 和 CLI 共享画布数据模型；脚本展开由同一 Core 操作生成节点和边。计费、套餐、成本优化和多人协作不参与当前优先级。

外部画布仅作为交互和布局证据。Open Canvas 保持独立名称、图标、素材、文案、数据模型和接口。

## 二、本地版功能边界

本地版的目标是一个可直接运行、可保存本地项目、可编辑节点图的创作工作台。UI 对齐的是画布结构与操作反馈，不是完整复制外部产品的账户与在线服务。

| 范围 | 本地版处理方式 |
| --- | --- |
| 项目与草稿 | 本地项目文件、草稿切换、JSON 导入/导出和本地快照；通过 CLI 打开时，Studio 经受限的回环桥接读取实际项目，并以显式保存写回。 |
| 素材 | 使用 `open-canvas asset import` 将图片或视频写入当前项目的本地素材存储；画布可用“本地素材引用”节点连接镜头，也可在图像/视频镜头内直接选择已导入素材作为输入引用。Studio 不直接访问文件系统，也不提供素材库侧栏。 |
| 生成任务 | 通过本地 CLI 或本地服务触发；画布只显示规范化任务状态和结果。图像镜头可请求 1、2 或 4 个候选，所有候选都写入当前项目，不形成全局素材库。 |
| 顶部栏 | 保留项目名、草稿切换、导入/导出与本地保存；不需要账号、空间、分享或在线 Agent 入口。 |
| 底部工具栏 | 保留添加节点、选择/抓手、自动整理、项目内分组、撤销/重做、缩放和帮助；不放置素材库、角色库、在线模板或历史面板入口。 |
| 历史 | 撤销/重做之外，生成节点可按需查看已被新版本替代的成功输出，并将其作为当前镜头的参考素材安全复用；不需要独立历史面板。 |
| 角色/风格 | 作为普通上下文节点存在，可直接连到镜头；它们的 Prompt 与已关联本地素材会成为镜头生成上下文，不提供角色库或风格库。 |
| 未实现的功能 | 无数据或无操作路径的面板不显示，不使用静态占位来模拟功能。 |

以下能力明确排除：登录、账号资料、在线空间、分享链接、成员协作、实时同步、充值/会员、额度、在线素材市场、客服、云端任务中心、素材库、角色库、风格库和独立历史面板。

## 三、验收口径

每一项画布能力应同时满足以下条件：

1. 用户可在 Studio 中直接操作并观察到结果。
2. 节点、边、布局和面板状态可写回并从项目文档恢复。
3. 关键状态具备同视口的本地截图与参考截图，或具备明确的交互记录。
4. 行为变更具备自动化测试或浏览器回归记录。

“视觉相似”只用于界面结构、信息密度和交互反馈；不代表复制外部产品的业务语义或素材。

## 四、画布基础能力

| 编号 | 能力 | 必须支持的行为 | 验收状态 |
| --- | --- | --- | --- |
| C-01 | 无限坐标系 | 节点、边、节点参数区共同随视口变换；顶部、底部和角落控制层固定。 | 必须 |
| C-02 | 空白处平移 | 左键拖拽空白处、空格拖拽、抓手工具、中键拖拽、触控板双指滑动均可平移。 | 必须 |
| C-03 | 缩放 | `⌘/Ctrl` + 滚轮、触控板双指捏合、缩放按钮、预设比例、适配视图和数值输入可用。 | 必须 |
| C-04 | 节点选择 | 初始无选中；单击节点只进入选中/参数态，不自动把视口重置到节点中心。 | 必须 |
| C-05 | 节点移动 | 直接拖动节点；移动后持久化坐标；移动节点不触发画布平移。一次单节点拖动只提交一次布局写入。 | 必须 |
| C-06 | 多选、分组与批量操作 | `Shift` 框选、`⌘/Ctrl` 点击追加/取消选择、批量移动和批量删除；`⌘/Ctrl+C`/`⌘/Ctrl+V` 复制粘贴选区内节点与内部连线，粘贴节点回到待生成状态；只有主选节点展开参数区。选择至少两个未分组节点后可通过工具栏或 `⌘/Ctrl+G` 创建持久化项目内分组帧；帧无端口、无任务，点击选中全部成员，拖动以一次原子布局写入移动全部成员。对齐和嵌套分组留在 V1.1。 | 必须 |
| C-07 | 连线创建 | 每个节点左右各保留一个可见端口；从输出端口拖到兼容输入端口创建有向边，边语义由节点类型推断，避免为不同边类型叠加多组端口；拖到无效端口时显示不含敏感信息的明确反馈，取消拖拽不提示错误。 | 必须 |
| C-08 | 连线管理 | 单击连线进入高亮选中态，`Delete`/`Backspace` 仅删除选中连线；同时支持显示/隐藏、边类型区分和方向反馈。 | 必须 |
| C-09 | 自动整理 | 预览布局、确认保留或还原；整理后适配视口。确认保留时以一次原子布局写入保存全部节点坐标。 | 必须 |
| C-10 | 网格与小地图 | 点阵背景、网格吸附、小地图显示/隐藏和缩放读数。 | 必须 |
| C-11 | 键盘导航 | `V` 选择、`H` 抓手、`N` 打开添加节点菜单、`Shift` 框选、`⌘/Ctrl` 追加选择、`⌘/Ctrl+C`/`⌘/Ctrl+V` 复制粘贴节点组、`⌘/Ctrl+G` 创建项目内分组、`Alt+Shift+F` 预览整理、`⌘/Ctrl+D` 复制聚焦节点、缩放、适配、撤销/重做、删除等快捷键。输入框、菜单和对话框打开时不劫持其文本编辑行为。 | 必须 |
| C-12 | 响应式画布 | 窄视口保持同一坐标系；固定工具栏不随画布移动；节点可横向溢出并通过平移查看。 | 必须 |

## 五、节点体系

### 5.1 节点的共同结构

每个实体节点至少包含以下数据和交互：

- 唯一标识、标题、类别、位置、尺寸策略和当前状态。
- 输入端口、输出端口、可连接类型和上游/下游关系。
- 简洁态、选中态、参数态、运行态、成功态和失败态。
- Prompt、参数、引用素材、结果素材、操作历史和错误信息。
- 节点内预览与“打开详情”入口；真实视频结果使用本地视频元素播放，演示封面图不伪装成可播放媒体。
- 创建、选中、移动、连接、复制、删除、重新执行和将历史结果安全复用为输入等操作。

节点尺寸遵循内容角色：文本/上下文节点采用近方形阅读面；图像和视频节点采用横向媒体面；参数区在选中后随节点一起变换。

### 5.2 画布实体节点

下表定义独立产品中的节点角色。角色按通用创作语义命名，不复制外部产品的名称或模型文案。

| 节点角色 | 类型类别 | 输入 | 输出 | 必须支持的节点功能 | 优先级 |
| --- | --- | --- | --- | --- | --- |
| 文本 | context | 文本、上游素材描述 | 文本上下文 | 编辑 Prompt/文案、引用上游、作为下游条件。 | 必须 |
| 脚本 | context | 创作主题、素材、文本 | 场景/镜头结构 | 创建和编辑故事、分场、镜头说明；可关联当前项目素材；共享 Core 操作按分行或句子展开为项目内视频镜头，并自动建立脚本依赖与镜头顺序。 | 必须 |
| 图像镜头 | generation | 文本、图像、风格/角色参考 | 图像资产 | Prompt、比例、尺寸、数量（1/2/4 个候选）、参考输入、结果预览和重新生成。数量是显式输出约束；路由不支持时在提交前拒绝。 | 必须 |
| 视频镜头 | generation | 文本、图像、角色/场景参考、音频要求 | 视频资产 | Prompt、比例、时长、音频、参考输入、结果预览和重新生成。 | 必须 |
| 编辑/变换 | transform | 图像或视频资产、编辑说明 | 新资产 | 在节点内关联当前项目的本地素材，记录裁剪、延展、替换、重绘、风格调整等意图；保留输入和输出版本。 | 必须 |
| 导演/镜头控制 | context | 脚本、镜头、素材 | 镜头约束 | 保存镜头语言、运镜、构图、镜头顺序和风格约束。 | 必须 |
| 画面分析 | analysis | 图像或视频资产 | 标签、描述、镜头/风格结构 | 在节点内关联当前项目的本地素材，提取可编辑分析结果，供脚本和生成节点引用。 | 必须 |
| 音频 | generation/context | 文本、时长、视频参考 | 音频资产或音频约束 | 在节点内关联当前项目的本地素材，管理旁白、音乐、音效和音画同步要求。 | 必须 |
| 角色设定 | context | 文本、参考图、已有资产 | 角色参考 | 管理外观、服装、表情和多视角设定，供多个镜头引用；它不是角色库条目。 | 必须 |
| 场景/风格 | context | 文本、参考图、已有资产 | 风格或场景参考 | 管理场景、视觉风格、特效和调色约束；它不是风格库条目。 | 必须 |
| 布局分组 | layout | 至少两个当前草稿节点 | 无生成输出 | 仅持久化成员 ID，派生低层级分组帧；点击帧选中成员、拖动帧整组移动；没有端口、任务、素材或跨项目资源语义。 | 必须 |
| 合成/输出 | composition | 多个镜头、音频、顺序关系 | 预览或导出目标 | 根据显式 `sequence` 边展示成片顺序，定义输出候选和最终主资产；多轨渲染后续接入。 | 必须 |

### 5.3 资源入口与面板的边界

以下入口不应被错误建模为没有数据职责的普通节点：

| 入口 | 画布行为 | 目标数据结构 |
| --- | --- | --- |
| 本地素材导入 | 通过 CLI 选择本地图片或视频，写入项目存储；Studio 从已导入的项目文档恢复资产元数据。 | 项目资产 + 素材引用节点 |
| 节点内素材选择 | 图像/视频镜头在参数区按需选择当前项目已导入素材，更新镜头 `inputAssetIds` 并使受影响结果待生成；新增文件仍通过 CLI 导入。 | 项目资产 + 镜头输入引用 |
| 上下文节点素材选择 | 角色、场景/风格、本地素材引用、剪辑、视频分析和音频节点在参数区按需选择当前项目已导入素材，更新 `referenceAssetIds`；不打开项目级素材库。 | 项目资产 + 上下文引用 |
| 节点结果历史 | 在单个节点内查看被替代的成功输出，并把某个输出作为当前镜头输入安全复用；不会直接用不同参数的旧结果覆盖当前输出。 | 节点结果版本 + 镜头输入引用 |
| 当前图像候选 | 在单个图像镜头内查看同一次生成的多个当前结果并打开预览；候选均保留为当前节点输出，可在后续节点作为项目内引用。 | 节点 `outputAssetIds` 的有序列表 |
| 角色/风格上下文 | 在画布上创建普通上下文节点，并连接到需要它的镜头。 | 上下文节点 + 引用关系 |
| 模板 | 后续需要时才提供；选择后创建多个实体节点及其连线。 | 图模板 |

## 六、节点状态与反馈

| 状态 | 可见反馈 | 可操作项 |
| --- | --- | --- |
| 未选中 | 类型、标题、缩略预览或占位、基础状态。 | 选择、移动、连接。 |
| 选中 | 外框高亮、左右端口、上方快捷配置、下方或旁侧参数区。 | 编辑参数、查看输入/输出、创建连线。 |
| 待执行 | 待更新提示、上游变更信息。 | 执行、查看变更、恢复旧版本。 |
| 排队/运行 | 进度、当前任务反馈、可用时的取消入口。 | 查看任务详情、取消。 |
| 成功 | 结果预览、媒体元数据、下游输入已更新提示。 | 打开预览、复用结果、重新生成。 |
| 失败 | 安全错误摘要和恢复建议；选中镜头可按需查看错误类型和下一步建议。 | 修改参数、从 Codex/CLI 重试、查看安全诊断。 |

## 七、固定 UI 层与面板

| 区域 | 必须支持的功能 | 对齐重点 |
| --- | --- | --- |
| 顶部栏 | 项目名称、草稿/画布切换、导入/导出和本地保存。 | 高度、层级、间距、按钮状态、窄视口收缩。 |
| 底部主工具栏 | 添加节点、选择/抓手、自动整理、项目内分组、撤销/重做、缩放、快捷键和帮助。 | 工具分组、图标尺寸、悬浮/按下/展开状态、固定位置。 |
| 添加节点菜单 | 实体节点、上传入口、分组标题和快捷创建。 | 菜单宽度、密度、层级、出现位置和关闭规则。 |
| 节点内资源操作 | P0 用 CLI 导入、画布引用、镜头内已导入素材选择和节点结果预览组成闭环；输入替换保持在节点参数区。 | 与参数区同层显示，不打开全局资源面板。 |
| 节点内历史 | 有被替代结果的节点提供历史结果查看与安全复用。 | 与节点结果关联，不打开全局历史面板。 |
| 模板入口 | 后续按需开启。 | 不属于初始本地画布的固定 UI。 |
| 左下控制组 | 自动整理、小地图、边显示、网格吸附、缩放。 | 组合方式、展开态、读数和固定定位。 |
| 空状态 | 无节点时的快速开始入口。 | 节点创建后自动消失、重置后恢复。 |

## 八、优先实现顺序

### P0：可用本地画布骨架

1. C-01 至 C-06：坐标系、平移、缩放、选择、节点移动和基础多选。
2. C-07 至 C-11：连线、自动整理、辅助控制和快捷键。
3. 文本、图像镜头、视频镜头、编辑/变换和合成/输出节点。
4. 节点选中态、参数态、结果预览与状态反馈。
5. 本地项目栏、底部工具栏、添加节点菜单、CLI 素材导入/画布引用和缩放控制。

### P1：本地创作上下文与工具层

1. 脚本、导演/镜头控制、画面分析、音频节点。
2. 本地快照、资源引用和节点模板。
3. 草稿切换、上下文节点复用和窄视口参数编辑。
4. 窄视口布局与全部面板状态。

### P2：高级编辑能力

1. 对齐、分组重命名、嵌套和解除分组等高级批量操作。
2. 时间线、多轨剪辑、转场、音频处理和渲染导出。

跨项目的全局角色、素材或风格库不在本地版路线中；需要移植内容时，使用项目 JSON 与项目内素材引用导出/导入，而不是连接一个在线资源中心。

## 九、对齐工作方式

每轮只处理一组可验证状态：

1. 采集一个参考状态及对应交互路径。
2. 在相同视口下打开本地画布，得到同类状态。
3. 对比节点几何、端口、边、控制层、文字密度和状态反馈。
4. 修复后使用浏览器实际操作，记录截图和自动化测试结果。
5. 未达到验收口径的状态保留在差异清单中，不以“整体相似”替代单项验证。

## 十、当前阶段的非目标

1. 商业化、价格、成本、额度、支付与套餐。
2. 多人实时协同、组织、权限与云端空间。
3. 登录、账号资料、在线空间、分享、在线素材市场、客服和云端任务中心。
4. 素材库、角色库、风格库、独立历史面板和在线模板市场。
5. 在浏览器或画布项目中保存用户的 API Key。
6. 复制外部画布的品牌、素材、文案、图标、私有接口或代码。
